AI &amp; Agent Design 9.1 Agent Architecture The Opportunity Agent operates as a continuous background process, not a single-turn chatbot. Its architecture follows a Perceive ΓåÆ Reason ΓåÆ Act loop: Loop Phase What happens Frequency PERCEIVE Ingest new opportunities from all configured sources. Detect profile changes (new skills, updated location, completed applications). Every 4 hours REASON Re-score all opportunities against updated profiles. Identify new high-match items. Detect upcoming deadlines (&lt; 7 days). Every 6 hours ACT Update opportunity feeds. Send deadline alerts. Trigger weekly digest. Surface proactive nudges (&quot;You qualify for 3 new opportunities this week&quot;). Event-driven + cron 9.2 LLM Usage Policy Resume parsing: claude-sonnet-4-6 with structured JSON output schema. Temperature 0. System prompt enforces field extraction only ΓÇö no hallucination of unstated experience. Opportunity description normalization: LLM summarizes verbose opportunity descriptions to 50 words for feed display. Faithful summarization, no embellishment. Match explanation (Phase 2): For each top-5 matched opportunity, generate a 1-sentence plain-English explanation of why it matches the student&apos;s profile. AI writing assistant (Phase 2): Student can request a draft cover letter or personal statement outline. Model given student profile + opportunity requirements as context. Output marked as AI-generated; student owns final edit. Guardrails: No fabrication of credentials. No generation of misrepresentative application materials. Rate-limited per student to prevent abuse. 9.3 Prompt Design Principles All LLM prompts version-controlled in the codebase alongside model version System prompt establishes role, output format, and constraints before user content Structured output (JSON schema) enforced for all extraction tasks ΓÇö no free-form parsing Prompt regression tests run on each deployment using a held-out golden set of 50 resumes LLM responses logged (excluding PII) for quality review and prompt iteration 10.
